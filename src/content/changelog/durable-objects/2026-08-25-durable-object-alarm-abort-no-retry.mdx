import { TypeScriptExample } from "~/components";

By default, `ctx.abort()` retries the current alarm after resetting a Durable Object. Pass `{ retryAlarm: false }` when the alarm should stop instead:

<TypeScriptExample filename="src/index.ts">

```ts
import { DurableObject } from "cloudflare:workers";

export class CleanupTask extends DurableObject {
	async alarm(): Promise<void> {
		await this.ctx.storage.deleteAll();

		this.ctx.abort("Cleanup complete", { retryAlarm: false });
	}
}
```

</TypeScriptExample>

For example, an alarm that deletes its storage can use this option to avoid repeating the cleanup or re-running the Durable Object constructor. Existing calls to `ctx.abort()` keep retrying alarms. `retryAlarm` does nothing outside an alarm handler.

For local development, `retryAlarm` requires Wrangler 4.126.0 or later.

For more information, refer to [`ctx.abort()`](/durable-objects/api/state/#abort).
